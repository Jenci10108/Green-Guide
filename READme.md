# 🌱 Green Guide

### Plant Identification and Care Website

Green Guide is a web-based platform that helps users identify plants and learn how to care for them using simple and accessible information.

## ✨ Features

- 🌿 Plant identification using uploaded images
- 🔬 Scientific plant names
- 🌍 Plant origin and native regions
- ☀️ Sunlight and temperature requirements
- 💧 Watering and soil information
- 🌱 Plant growth and planting seasons
- 🌳 Tree health visual assessment

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PlantNet API

## 🎯 Project Objective

To help people identify plants, understand their requirements and learn basic plant care through an easy-to-use website.

## ⚠️ Disclaimer

Tree health assessment is based on visual observations only. It is not a professional diagnosis.
